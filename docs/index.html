1. ข้อมูลเกมบนอุปกรณ์
เกมไม่ต้องสมัครบัญชี ไม่มีการแชทหรือระบบส่งเนื้อหาให้ผู้เล่นคนอื่น ความคืบหน้า คะแนน การตั้งค่าเสียง และกลุ่มอายุถูกเก็บในพื้นที่ของแอปบนอุปกรณ์ เกมใช้ตัวเลขอายุเพื่อเลือกกลุ่มอายุเท่านั้น ไม่บันทึกวันเกิดหรืออายุที่กรอกไว้ ผู้พัฒนาไม่มีฐานข้อมูลบัญชีผู้เล่น ข้อมูลในเครื่องอาจถูกสำรองหรือย้ายโดย Android ตามการตั้งค่าอุปกรณ์ของคุณ

2. โฆษณาและบริการของ Google
เกมใช้ Google Mobile Ads SDK และ User Messaging Platform (UMP) เพื่อแสดงแบนเนอร์ โฆษณาระหว่างด่าน โฆษณาที่เลือกรับรางวัล และจัดการตัวเลือกความเป็นส่วนตัว รุ่นทดสอบใช้รหัสโฆษณาทดสอบและยังไม่สร้างรายได้ แต่ SDK อาจติดต่อเซิร์ฟเวอร์และประมวลผลข้อมูลได้
Google อาจเก็บและแบ่งปันที่อยู่ IP (ใช้ประมาณตำแหน่งโดยทั่วไป) การเปิดแอป การแตะและการดูโฆษณา ข้อมูลวินิจฉัย/ประสิทธิภาพ รวมถึงรหัสอุปกรณ์ เช่น Advertising ID และ App Set ID เพื่อให้บริการโฆษณา วิเคราะห์ และป้องกันการฉ้อโกง ข้อมูลที่ส่งโดย SDK ใช้การเข้ารหัสระหว่างส่ง (TLS) ข้อมูลและระยะเวลาเก็บรักษาของ Google อยู่ภายใต้นโยบายของ Google:
https://policies.google.com/privacy
https://policies.google.com/technologies/ads
ไม่มีการขอสิทธิ์เข้าถึงตำแหน่ง GPS รายชื่อผู้ติดต่อ กล้อง หรือไมโครโฟน เสียงในเกมสร้างขึ้นภายในแอป ไม่ใช่การบันทึกเสียงผู้เล่น

3. อายุและตัวเลือกโฆษณา
เกมมีกลุ่มเป้าหมายอายุ 13 ปีขึ้นไป เมื่อระบุอายุต่ำกว่า 13 ปี เกมจะไม่ให้เข้าเล่นและไม่เริ่ม SDK โฆษณา สำหรับผู้เล่นอายุ 13–17 ปี เกมส่งคำขอให้ Google ใช้การป้องกันสำหรับผู้ที่อายุต่ำกว่าเกณฑ์ให้ความยินยอม โดยไม่ใช้โฆษณาเฉพาะบุคคล สำหรับผู้ใหญ่ เกมใช้ขั้นตอนความยินยอมของ UMP ตามพื้นที่ที่เกี่ยวข้อง ก่อนขอโฆษณาจะตรวจสิทธิ์จาก UMP หากไม่มีสิทธิ์ เกมยังเล่นต่อได้โดยไม่มีโฆษณา
เมื่อ Google กำหนดให้มีตัวเลือกความเป็นส่วนตัว สามารถเปิดได้จากหน้าพักเกม คุณยังจัดการหรือลบรหัสโฆษณาใน Android ได้

4. การเก็บรักษาและการลบ
ข้อมูลความคืบหน้าและการตั้งค่าจะอยู่จนกว่าคุณจะล้างข้อมูลแอปหรือถอนการติดตั้ง การล้างข้อมูลจะลบความคืบหน้าและการตั้งค่าบนอุปกรณ์ ไม่ใช่คำสั่งลบข้อมูลที่ Google ประมวลผลไว้ หากมีข้อมูลสำรอง ให้จัดการแยกในบริการสำรองของ Android
ผู้พัฒนาไม่ได้รับสำเนาฐานข้อมูลผู้ใช้จาก SDK หากคุณติดต่อทางอีเมล ผู้พัฒนาจะได้รับอีเมลและรายละเอียดที่คุณเลือกส่งเพื่อแก้ปัญหา จะเก็บเท่าที่จำเป็นต่อการช่วยเหลือและหน้าที่ตามกฎหมาย คุณสามารถติดต่ออีเมลข้างต้นเพื่อขอเข้าถึง แก้ไข หรือลบข้อมูลที่ผู้พัฒนาถืออยู่ ส่วนข้อมูลของ Google ให้ใช้เครื่องมือและช่องทางตามนโยบายของ Google

5. การเปลี่ยนแปลง
หากเปลี่ยน SDK รูปแบบการใช้ข้อมูล หรือเปิดโฆษณาจริง จะปรับนโยบายและข้อมูลใน Google Play ให้ตรงกับรุ่นที่เผยแพร่ วันที่ด้านบนระบุฉบับล่าสุด
